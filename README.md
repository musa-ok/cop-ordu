# Çöp Ordu

3B savaş alanında kendi ordunu kur: altınınla asker, okçu, atlı, dev ve tank al, karelere diz, düşman ordusunu yen. Her bölümde düşmanın dizilişi ve birlikleri değişir; 15. bölümden sonra sonsuz mod başlar.

Oyna: https://musa-ok.github.io/cop-ordu/

Şövalye, at ve tank modelleri: [Quaternius](https://quaternius.com) (CC0). Ayrıntılar: [models/CREDITS.md](models/CREDITS.md)
